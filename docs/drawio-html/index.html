How the drawing becomes a web page

The page loads the original XML from data.js. The bundled draw.io renderer creates an SVG using the saved geometry. A separate mapping attaches URLs by the original cell ID. A before-and-after check verifies that adding those links did not change the drawing.

Edit a URL in drawio-links.json, then run python3 build.py in this folder. The mapping guide explains the fields, examples and checks. Drawing links need internet access; the drawing itself renders locally.
